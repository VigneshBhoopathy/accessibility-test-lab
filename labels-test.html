Labels Accessibility Test Page

This page contains intentional label accessibility defects for Playwright testing.

LABEL-001 - Input Without Label

This input has no associated label.

LABEL-002 - Empty Label

This input has an associated label, but the label contains no descriptive text.

LABEL-003 - Unclear Label

The label is present and associated with the input, but it does not clearly describe what information should be entered.

LABEL-004 - Incorrect Label

The label is associated with the input, but it does not accurately describe the purpose of the input.

LABEL-005 - Required Field

This field is required, but the visible label does not communicate that the field is required.

LABEL-006 - Correctly Labelled Input

This input has a clear and correctly associated label.
